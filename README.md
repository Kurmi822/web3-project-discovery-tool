# Web3 Project Discovery Tool

An AI-powered Web3 discovery and tracking platform.

This tool helps users discover:

- New blockchain projects
- Testnets and node programs
- Early airdrop opportunities
- Community activities

## Features

- Track early Web3 projects
- AI-based project discovery
- Web3 opportunity alerts
- Blockchain ecosystem monitoring

## Tech Stack

- Node.js
- Web3 APIs
- Simple AI filtering logic

## Installation

git clone https://github.com/yourusername/web3-project-discovery-tool.git

cd web3-project-discovery-tool

npm install

node app.js
